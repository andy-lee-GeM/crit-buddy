# Report Sections

Use this order for the handoff report unless the user asks for something else:

1. `Purpose`
2. `Model Overview`
3. `Configurable Parameters`
4. `Modeling Assumptions`
5. `Material Definitions`
6. `Solver / Analysis Setup`
7. `Benchmarking`
8. `Engineering Use of the Model`
9. `Parameter Sensitivity / Lookup Sweeps`
10. `Limitations`
11. `Appendix`

## Appendix Expectations

Keep the appendix practical.

Include:

- a short note that `models/model.py` is the runnable OpenMC reference model
- a short note that `models/model.inp` is the runnable MCNP reference model
- material-library references
- selected supporting artifact references

Do not use the appendix to hide the actual benchmark evidence. The benchmark
table belongs in the main body.
